# 📚 Repositório de Estudos: CI&T Backend Java Bootcamp (DIO)

Este repositório é dedicado a armazenar materiais, códigos de exemplo e anotações geradas durante o bootcamp **CI&T Backend Java**, oferecido em parceria com a **DIO (Digital Innovation One)**.

O objetivo principal deste curso é fornecer uma formação completa, partindo dos fundamentos da linguagem Java até o desenvolvimento de APIs robustas e modernas.

---

## 🎯 Foco do Repositório

O conteúdo aqui presente segue a trilha de aprendizado do bootcamp, focando em estabelecer uma base sólida na linguagem Java, essencial para qualquer desenvolvedor Backend.

## 📝 Tópicos e Conceitos Abordados

Abaixo estão os principais conceitos e módulos de estudo documentados neste repositório:

### Fundamentos da Linguagem Java

*   **Sintaxe Básica:** Variáveis, operadores, estruturas de controle de fluxo (`if/else`, `while`, `for`).
*   **Programação Orientada a Objetos (POO):** Classes, objetos, herança, polimorfismo, encapsulamento e abstração.

### Estruturas de Dados e Manipulação

*   **Collections Framework:** Estudo e aplicação das principais estruturas de dados (List, Set, Map) e suas implementações.
*   **Manipulação de Strings:** Análise detalhada e diferenças práticas entre `String`, `StringBuffer` e `StringBuilder`.

### APIs Nativas e Recursos Avançados

*   **Tratamento de Exceções:** Implementação de `try-catch-finally` e criação de exceções customizadas para garantir a robustez do código.
*   **API de Streams e Generics:** Utilização de Streams para manipulação eficiente de coleções e aplicação de Generics para código mais seguro e reutilizável.
*   **API de Data e Hora (java.time):** Uso de classes modernas como `OffsetTime`, `LocalDate` e `LocalDateTime` para manipulação precisa de datas e fusos horários.

### Outros Conceitos Essenciais

*   Empacotamento e visibilidade de classes e métodos.
*   Conceitos de I/O (Input/Output).

## 🛠️ Pré-requisitos

Para executar os códigos de exemplo contidos neste repositório, você precisará ter instalado:

*   **Java Development Kit (JDK):** Versão 17 ou superior (recomendado).
*   **IDE:** IntelliJ IDEA, Eclipse ou VS Code.
